# Body-Detection-System-
This module focuses on detecting body landmarks from an image using AI. Different body points are identified and connected to create a body structure, helping to understand posture and movement. It acts as the first step for body measurement and virtual fitting systems.
For this task, I used OpenCV and MediaPipe to perform human body landmark detection through a webcam. The camera captured live input and the system detected body points automatically to generate a body skeleton. This helped in visualizing body posture and tracking body positions in real time.
